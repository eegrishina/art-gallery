# Art Gallery

### [Демонстрация проекта на GitHub Pages](https://eegrishina.github.io/art-gallery/)

## Описание проекта

Проект выполнен в рамках тестового задания для компании **ООО "Экосистема Альфа"**.  
Цель разработки — создание **Single Page Application (SPA)**, отображающего список карточек с изображениями и информацией, полученной из публичного API, с возможностью управления карточками.

> **Стэк: Typescript \ React \ Redux || Zustand**


## Используемое API

Для получения данных использовалось [The Metropolitan Museum of Art Collection API](https://metmuseum.github.io/#departments).


## Функционал

### Основные возможности проекта:

1. **Список продуктов**:
   - На странице `/products` отображается список карточек.
   - На карточке:
     - **Изображение** (или placeholder, если изображение отсутствует).
     - **Текстовый контент**: текст обрезается для обеспечения одинаковой высоты всех карточек.
     - **Иконка лайка**: позволяет добавлять/удалять карточку в избранное. Иконка меняет цвет при активации.
     - **Иконка удаления**: удаляет карточку из списка.
   - Возможность переключаться между всеми карточками и избранными через фильтр.
   - При клике на карточку (кроме иконки лайка и кнопки удаления) пользователь переходит на страницу карточки.

   ✳️ **Бонус: реализована пагинация как для полного списка карточек, так и для избранных.**

2. **Страница продукта**:
   - На странице `/products/:id` отображается подробная информация о карточке.
   - Добавлена кнопка для возврата на основную страницу.
   - **Дополнительно:** реализована кнопка добавления/удаления карточки в список избранного.

3. **Создание продукта**:
   - На странице `/create-product` можно создать новую карточку.
   - Реализована форма с минимальной валидацией обязательных полей. Для специфичных данных, таких как URL изображения, добавлены паттерны валидации.
   - После отправки формы данные сохраняются в общий store, и пользователь перенаправляется на созданную карточку по адресу `/products/:id`.
   - Добавлена кнопка для возврата на основную страницу.

> **Дополнительно: реализована базовая адаптивность страниц проекта для корректного отображения на устройствах с разными размерами экрана.**

## Используемые технологии

- **React**: разработка пользовательского интерфейса.
- **TypeScript**: типизация кода.
- **Redux**: управление состоянием приложения.
- **React Router**: навигация по страницам.
- **React Hook Form**: управление формами.
- **CSS Modules**: стилизация компонентов.


## Установка и запуск

1. Склонируйте репозиторий:
   ```
   git clone <repository-url>
   ```
2. Перейдите в папку проекта:
   ```
   cd art-gallery
   ```
3. Установите зависимости:
   ```
   npm install
   ```
4. Запустите приложение:
   ```
   npm run dev
   ```

После этого приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173).
